# Voltara Dashboard

แดชบอร์ดสรุปผลบริษัทพลังงาน Voltara (ข้อมูลจำลอง ม.ค. 2024 – ธ.ค. 2025) เล่าเรื่อง 5 บท

1. **ปัญหา**: ค่าไฟครัวเรือนสูงและผันผวน บิลบ้าน 400 หน่วยเทียบก่อน/หลังติดโซลาร์
2. **ลูกค้า**: ลูกค้าติดตั้ง 5 กลุ่ม (บ้านพักอาศัย, ร้านค้า/SME, โรงงาน, อาคารพาณิชย์/โรงแรม, เกษตร/ฟาร์ม)
3. **ผลงาน**: รายได้ตามกลุ่มธุรกิจ (ธุรกิจบริการโตเร็วกว่าการขายไฟ) และต้นทุนตามหมวด 4M รวมค่าเชื้อเพลิงก๊าซที่ผูกกับคู่ค้าหลัก
4. **ESG**: CO₂ ที่ลดได้ นับเฉพาะไฟจากโซลาร์ฟาร์มและระบบที่ติดตั้งให้ลูกค้า ไม่นับไฟจากโรงไฟฟ้าก๊าซ
5. **ก้าวต่อไป**: ข้อเสนอจากตัวเลขในบทที่ 1–4

## ผู้จัดทำ

- ชลธี กิมสร้อย 67160325

## โครงสร้างไฟล์

```
voltara-dashboard/
├── index.html          แดชบอร์ด (เปิดด้วยเบราว์เซอร์ได้เลย)
├── generate_data.py    สคริปต์สร้างข้อมูลจำลอง + data_dictionary.md
├── data_dictionary.md  คำอธิบายคอลัมน์และตัวเลขสรุป
└── data/
    ├── revenue.csv
    ├── generation.csv
    ├── co2_reduction.csv
    ├── costs.csv
    ├── customers.csv       ลูกค้าติดตั้ง 5 กลุ่ม
    ├── household_bill.csv  ค่าไฟครัวเรือน
    └── data.js         ข้อมูลชุดเดียวกับ CSV สำหรับ index.html
```

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ได้เลย ต้องต่ออินเทอร์เน็ตเพราะโหลด Chart.js จาก cdnjs

ถ้าแก้ข้อมูล ให้แก้ใน `generate_data.py` แล้วรันใหม่ สคริปต์จะสร้าง CSV, `data.js` และ `data_dictionary.md` ใหม่ทั้งหมด ตัวเลขทุกที่จึงตรงกันเสมอ

```bash
python3 generate_data.py
```

## สมมติฐานหลัก

- Grid Emission Factor = 0.4999 tCO₂/MWh (อิงค่าของ TGO) ใช้กับไฟจากโซลาร์เท่านั้น
- ราคาขายไฟ PPA ประมาณ 3.6 บาท/kWh ค่าเชื้อเพลิงก๊าซประมาณ 2.45 บาท/kWh
- โซลาร์ฟาร์ม 35 MW (2024) ขยายเป็น 37 MW (2025) ผลผลิต 1,468 / 1,474 MWh/MW/ปี อยู่ในช่วงปกติ 1,400–1,500
- ระบบลูกค้าผลิตไฟตามกำลังผลิตสะสมจากยอดติดตั้ง × 1,450 MWh/MW/ปี
- ค่าไฟครัวเรือนเป็นค่าประมาณอิงประกาศ กกพ. ควรตรวจกับแหล่งจริงก่อนอ้างอิง
- ข้อมูลเป็นข้อมูลจำลอง (seed = 67160325) ไม่ใช่ข้อมูลจริงของบริษัทใด
